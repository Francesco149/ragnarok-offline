Evidence for Thread #9: Refining Details (Prices, DEF Math, Card Destruction)

Source 1: iRO Refine System Page
URL: https://web.archive.org/web/20040605070057/http://iro.ragnarokonline.com:80/game/refinesystem.asp
Date: 2004-06-05
Passage:
"If you succeed in upgrading, a 'SUCCESS' message will display and the item will have a +1 added to it. If the upgrade fails, the item, Zeny used, and any cards in the slots will all be destroyed completely, so please be aware of the following."

Source 2: kRO Patch Notes 2003-02-04
URL: https://ragnarok.fandom.com/api.php?action=parse&page=RO_Patch_(2003_Feb._04)&prop=wikitext&format=json
Date: 2003-02-04
Passage:
"무기나 방어구를 제련하다가 실패했을 경우 해당 무기는 완전히 없어지도록 변경 되었습니다.
무기레벨 4 의 무기를 제련하면 +1 당 7의 공격력 증가를 가져오도록 변경 하였습니다.
제련으로 인한 추가 DEF 는 순수한 방어구의 DEF 보다 효율이 낮게 변경 되었습니다.
방어구가 안전하게 제련되는 수치를 +5 → +4 로 변경 하였습니다."
(Failed upgrade completely destroys item; Lv 4 weapon gains +7 ATK per refine; refine DEF has lower efficiency than pure armor DEF; armor safe refine reduced from +5 to +4).

Source 3: Armor Refine DEF Formula in eAthena / rAthena refine_db.txt
Date: 2004
Passage:
"// Armor defense is done in percentage (ie 70 = .7 def)
 70, 4,4, 100,100,100,100, 60, 40, 40, 20, 20, 10,	// Armor"
Calculation in battle.c / status.c:
"refinedef += sd->status.inventory[index].refine * refinebonus[0][0];
sd->def += (refinedef + 50) / 100;"
Each armor refine level grants +0.7 DEF.

Source 4: Phracon and Emveretarcon Pricing
Files: data/db/items.toml, eathena-npc.rar refiners.txt
Passage:
Phracon: buy = 200z (sell = 100z).
Emveretarcon: buy = 1000z (sell = 500z).
The "2000z" on iRO's website was an editorial web typo (it conflated the armor refine fee of 2000z with Phracon price).
Refine fees charged by NPC:
- Weapon Lv 1: 50z + Phracon
- Weapon Lv 2: 200z + Emveretarcon
- Weapon Lv 3: 5,000z + Oridecon
- Weapon Lv 4: 20,000z + Oridecon
- Armor: 2,000z + Elunium
