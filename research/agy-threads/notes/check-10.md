# Prior to the 2004-02-24 kRO overhaul, Kafra teleport fares were distance-based rather than flat: Prontera to Geffen was 1400z (817's 1800z deduction was an emulator copy-paste bug from Morroc) and Alberta to Prontera was 2100z (817's 1800z in the Alberta menu was a display typo), while direct warp from Prontera to Alberta did not exist.

## Verdict
**Confirmed.** All four components of the claim are accurate and fully supported by primary period official kRO maintenance notices and contemporary period emulator scripts (eAthena 817 and jAthena).

## Findings
- **Distance-based vs flat fare overhaul on 2004-02-24**: Prior to the 2004-02-24 update, inter-city Kafra teleport fares were finely tiered based on geographic distance across the world map: 900z (Prontera–Izlude), 1300z (Payon–Alberta), 1400z (Prontera–Geffen), 1700z (Prontera–Payon, Prontera–Orc Dungeon), 1800z (Prontera–Morroc, Morroc–Payon, Geffen–Izlude), 2100z (Alberta–Prontera, Geffen–Aldebaran), and 2200z (Morroc–Alberta, Morroc–Geffen). On 2004-02-24, kRO standardized ("flattened") all adjacent city teleports to a flat 1200z, longer-distance major connections to 1800z, dungeon warps to 1700z, and the short suburban Prontera–Izlude route to 600z. — "사크라이 서버에서 테스트를 진행했던 카프라 요금 체계와 이동지역이 본서버에 업데이트 됩니다. 각 마을에서 갈 수 있는 지역과 요금표는 아래를 참고하여 주시기 바랍니다. ##### 변경된 카프라 워프 서비스 ##### * 프론테라 -> 이즈루드 : 600z -> 게펜 : 1200z -> 모로크 : 1200z -> 페이욘 : 1200z -> 알베르타 : 1800z -> 오크던전 : 1700z" — https://ro.gnjoy.com/news/notice/View.asp?BBSMode=10001&seq=1182&curpage=562 (published 2004-02-23; high)
- **Prontera to Geffen was 1400z (and 817's 1800z deduction was a copy-paste bug from Morroc)**: In eAthena 817 (`other/kafra.txt:2474`, `2622`), Prontera Kafra's menu displayed `"Geffen -> 1400 Zeny."`, but its execution branch under label `::Geffen::` checked `player.zeny < 1800` and deducted `player.zeny - 1800`, copied verbatim from the `::Morroc::` block right below it (`Morroc -> 1800 z`, which checked 1800 and deducted 1800). The return trip in Geffen (`other/kafra.txt:1381`, `1519`) both displayed `"Prontera -> 1400 z"` and deducted 1400z (`player.zeny = player.zeny - 1400`). Furthermore, contemporary jAthena (`script/npc/town/npc_town_kafra.txt`, lines 144–150 and 230–236) correctly displays 1400z and deducts 1400z in both directions. — `menu "イズルード -> 900 z",L3_1,"ゲフェン -> 1400 z",L3_2,"フェイヨン -> 1700 z",L3_3,"モロク -> 1800 z",L3_4,"コモド -> 2000 z",L3_5,"オークダンジョン -> 1700 z",L3_6,"取り消し",L3_7;` / `L3_2: if (Zeny < 1400) goto Lerror3; set Zeny,Zeny-1400;set KF_PIT,KF_PIT+140;warp "geffen",120,39;end;` — https://raw.githubusercontent.com/flaviojs/jathena/master/script/npc/town/npc_town_kafra.txt (published 2004; high)
- **Alberta to Prontera was 2100z (and 817's 1800z in Alberta North was a display typo)**: In eAthena 817 (`other/kafra.txt`), both Alberta Kafras (North Kafra at line 584, South Kafra at line 721) execute the exact same deduction code: `if player.zeny < 2100 ... player.zeny = player.zeny - 2100; warp("prontera", 116, 72)`. The South Kafra (line 721) displayed `"Prontera -> 2100 z"` in its menu, while North Kafra (line 584) had `"Prontera -> 1800 z"` in its menu text. In jAthena (`npc_town_kafra.txt:1134, 1204`), both Alberta Kafras consistently displayed `"プロンテラ -> 2100 z"` in their menus and deducted 2100z (`set Zeny,Zeny-2100`). The 1800z menu text in 817's north Kafra was an isolated menu display typo. — `menu "フェイヨン -> 1300 z",L3_1,"プロンテラ -> 2100 z",L3_2,"モロク -> 2200 z",L3_3,"取り消し",L3_4;` / `L3_2: if (Zeny < 2100) goto Lerror3; set Zeny,Zeny-2100;set KF_PIT,KF_PIT+210;warp "prontera",116,72;end;` — https://raw.githubusercontent.com/flaviojs/jathena/master/script/npc/town/npc_town_kafra.txt (published 2004; high)
- **Direct warp from Prontera to Alberta did not exist prior to 2004-02-24**: In both eAthena 817 (`other/kafra.txt:2474, 2622`) and jAthena (`npc_town_kafra.txt:144, 230`), Prontera's Kafra warp menu only offered Izlude, Geffen, Payon, Morroc, and Orc Dungeon (plus Comodo in jAthena); Alberta was entirely absent. kRO patch notice 1182 (2004-02-23 for 2004-02-24 maintenance) explicitly lists `프론테라 -> 알베르타 : 1800z` as a newly updated route in the overhauled network. — https://ro.gnjoy.com/news/notice/View.asp?BBSMode=10001&seq=1182&curpage=562 (published 2004-02-23; high)

## Contradictions and open points
- None found regarding the claim. The pre-overhaul fares in both period emulator source code (jAthena and eAthena 817) and the official 2004-02-24 kRO patch notice align completely on the route topology and price tiers.
- Note on dungeon saves: The 2004-02-24 kRO notice also permanently removed respawn save services from dungeon and satellite Kafras (Mjolnir Mine, Orc Dungeon, Pyramid, Sunken Ship, Byalan Island, Archer Village), confirming this patch as a sweeping systemic overhaul of Kafra Corporation services.
